NABU 1.18 · EVERYWHERE CAPTURE

Extract the whole folder before starting.
Windows users can double-click Start-Nabu.cmd.
On macOS open Start-Nabu.command. On macOS or Linux you can run bash start-local.sh.
The full app uses Python 3.11 or newer and downloads its pinned dependencies on first setup.
Open http://127.0.0.1:8000/explore and keep the terminal open.

For a guest preview with Python and no dependency downloads, run
python -m http.server 8080 --directory public
from this folder and open http://127.0.0.1:8080/.

On Explore, open The bend in the road and tap its line, or select Watch the Moments walkthrough.
The scrolling Capture demo is linked under the film and in the sidebar.
START_HERE.md explains upgrading with your existing .data, .env.local, profile and exact origin.
docs/NABU_1.18.md contains the examples, measurements, assumptions and replay instructions.
