# Nabu 1.17 r3: Pages and colour templates

Build: `nabu-pages-1.17-20261116-r3`, November 16, 2026 Eastern. This update restores the original forest green (#24624f) and adds locally saved Original green, Lapis, Clay and Plum palettes in Settings. Changes apply immediately, with success/failure states, and unknown saved values fall back safely. Existing learning data is preserved. No backend dependencies or model rules changed.

The complete source folders are uploaded directly through GitHub, preserving their paths. The Pages workflow has read-only access to repository content; it builds and tests source before publishing only `public/`. The deploy job has only Pages and OIDC deployment permissions. No workflow can modify `main`. The release archive remains a complete portable download, including executable launcher metadata. Web-uploaded loose launcher files can be run with `bash start-local.sh` on macOS/Linux or `py -3 start_local.py` on Windows.

GitHub Pages provides the browser application: contextual offline-bank lookups, local vocabulary/notes/review, reading aids, graph and learner tools, local media and palette preferences. It cannot run the Python account, assignment, departmental reporting or cloud-provider services. Settings identifies that boundary; the local full-stack launchers remain available. No provider key is embedded. External services remain conditional and require their existing permissions.

Local verification: 872 JavaScript tests and 106 DOM tests passed. Seven new checks cover preference validation, host classification, template contrast, complete Pages startup without API requests, persisted preference restoration, save-failure retry and corrupt preference recovery. The full regression counts include those new checks. The standalone and optional mobile web bundles rebuilt successfully. The prior r2 backend suite had 522 passes; backend behavior was not changed or represented as rerun in this update. Live Pages verification and Actions results are recorded in the final handoff after deployment.

Default green, template text and primary buttons meet the tested normal-text contrast threshold. Native keyboard, narrow viewport, reading/save/refresh, palette/refresh and actual hosted paths still require the live browser checks; passing DOM tests alone does not certify them.
