# Nabu 1.18 · Everywhere Capture

The website opens on a Lebanese Arabic road scene. Tap the line for its meaning, choose **Keep for practice**, then try the question at the doorway. Select **French** for the Camille dialogue or **Spanish** for another paired scene. From the French passage you can inspect the historical answer key, challenge its inference, and see the reviewed answer after reopening the passage.

Under **Watch the Moments walkthrough**, the 39-second film shows the examples in the private Moments preview. **Capture demo** opens the scrolling feed with translucent bubbles. Both demos are bundled locally. The feed demonstrates the intended mobile interaction. Real host-app capture and device permissions require their own native release and device verification.

Open the avatar in the top bar, then choose a collection under **Your avatar**. Each of the twelve language collections offers a feminine and masculine interpretation of Nabu. Choose either portrait or restore your initial. The selection is stored per profile on this device and can be changed independently of the languages you study.

The website uses the same origin, saved-material stores and versioned content history as 1.17. To run the full local application use the included launcher. The plain static version can be served with Python from the extracted project using `python -m http.server 8080 --directory public`.

The underlying model and the synthetic examples are described in [the Moments review](NABU_3_MOMENTS.md) and [the support-cycle guide](SUPPORT_CYCLE.md).

The review selector matches a response to the same target, task, modality and variety before proposing repair or another context. Policy version 2 accepts earlier version 1 event histories. The return count starts when a learner chooses practice. Opening a new scene is counted separately from reopening the saved passage.
