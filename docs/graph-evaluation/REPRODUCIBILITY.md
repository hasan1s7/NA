## What is fixed and what is assumed

There are 12 fixed seeds, 5 arities, and 128 subsets per seed/arity: **7,680** distinct evaluation cells, with both representations assessed on each. The first two subsets in every cell are forced empty/full boundaries; the other 126 are generated by a keyed hash and a threshold of one half. Means and sample SD are over fixed-seed metric values, not confidence intervals about people.

Synthetic `verified` statuses are stipulated software inputs. Fictional `zzfixture_...` forms are not claimed to be valid language. The conjunction oracle is independently declared set inclusion. Flattened-edge reachability is intentionally lossy; retaining factors and all input ports avoids the counterexample even when ordinary graph primitives implement that representation.

Source copies share a declared lineage. The experiment neither discovers hidden dependencies nor proves independence for different labels. The task-support filter is supplied correctly by construction; it is not a learned relevance model. Truncated answers remain explicitly incomplete, and all current reader annotations preserve null bank/lexeme/sense links.
