## Corrections made during this work

Initial JS failures were stale old-build identifiers in service-worker/startup assertions; these were updated to the actual release ID and the full suite rerun. A new search test exposed that literal-image vocabulary was not discoverable; search indexing now includes it without changing exact translation resolution. Preview tests initially used an ambiguous selector, closed an already auto-closing import dialog, and assumed a particular review card without choosing its collection. These harness issues were fixed by scoped selectors, waiting for completion, and selecting the intended collection. The final clean rerun passed all suites.

One combined parallel run timed out; no result from that interrupted run is counted. Python/API completed separately with 193 passes in 38.85 seconds. Final browser suites were run sequentially. The complete final logs and machine-readable results are included.

## Linguistic scope

Complete source/target coverage is a schema property, not proof of perfect equivalence. A few idiom sense references are included for traceability; they do not certify the twelve translations or original examples.
