### New test cases and fixes

- Two independent JS sync-module instances (simulated tabs) acquire the same per-user Web Lock. They do not concurrently send an already-acknowledged operation. Without Web Locks, server UUID receipts still prevent duplicate commits; cross-tab exclusion is not guaranteed in unsupported browsers.
- A second card queued while the server is acknowledging a first card remains in the outbox and is flushed. After `configure`, a warm cache is explicitly **cached / checking**, not falsely presented as **synced** until the server is checked.
- Encrypted S3 uploads include SHA-256 metadata and verify the server's HEAD size *and* metadata; local status records the ciphertext hash and object key only after success.
- `verify_offsite_backup.py` downloads the selected encrypted object, verifies its SHA-256 checksum, decrypts and validates SQLite into an isolated temporary path, confirms sessions are revoked, and leaves the production database unchanged. Tests cover success, a wrong encryption key, same-size remote corruption and local-only backups. No real bucket was used.
- Backup status monitoring optionally requires a successful restore drill (`--require-restore-drill`). A failed or stale drill does not become green.

## Important verification limits

Attempted an unmodified, native browser account acceptance test against a **local**, isolated Nabu server at `127.0.0.1:8100`. The HTTP health endpoint responded OK, but the browser refused page navigation with `net::ERR_BLOCKED_BY_ADMINISTRATOR` **before the native account tests could execute**. This is a block, not a failed app test or a passed hosted test. Consequently, real browser IndexedDB durability, service-worker reload, cookie behavior over HTTPS, multi-tab Web Locks on actual devices, and hosted startup remain unverified. An isolated local database was used; no production database or real users were touched.

No real S3 upload/download or scheduled restore was performed. No deployment, DNS setup, payment, external API request, real pronunciation check, independent linguistic review, FSRS replay, professional security audit, or large-load test was performed. The existing phrasebank remains an unreviewed draft; no claim of native-verified translations is warranted.
