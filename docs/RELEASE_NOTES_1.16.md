# Nabu 1.16 release notes

Built from the supplied Nabu-1.15.0-Launchers-Fixed(1).zip. “Nabu 1.2” is the design vision; the release is **1.16.0**.

## Changes

- Content-first reader and Explore layout, warm paper/clay surfaces and restrained lapis accents. Optional intentions, next steps and learner evidence are available below the content in a disclosure.
- At a glance and In depth share one explanation panel in the reader and word bank. Switching toggles the depth section without replacing source, media, pending requests, council drafts or saved state. The mode preference persists; new users start at a glance.
- Exact highlighted source context remains distinct from additional examples. Repeated words now highlight the selected occurrence; selected phrases remain visibly marked.
- Available in-depth usage/grammar notes, literal wording, bank examples, source attribution, editable notes, reading aids and existing structure diagnostics. Dictionary coverage and editorial uncertainty remain explicit.
- Saved corrected meanings take priority over fresh lookup output, including the quick-translation display, speech and copy actions. In-depth comparison preserves the lookup version. Saving retains the existing uniqueness and revision checks.
- Original locally bundled vector Nabu with expandable Listening, Working, Explaining and Uncertain states. Quiet and hidden settings; useful failure/evidence/repair text; no learner-directed irritation.
- Complete agreed Council of Twelve Tongues roster. The relevant pair appears on request in depth, with a question field and an optional translation setting. No conversational AI adapter exists in the source application: the server and UI explicitly report this dependency and do not invent dialogue. No new paid provider or credentials.
- Device-local own-text resume, selection and scroll checkpoints, scoped by account. Saved vocabulary remains in the existing storage/sync system. Existing curated reading progress is unchanged.
- Optional local audio/video beside a pasted transcript, retained DOM/playback position across explanation modes, no uploads, and last-time restoration when the same file is reselected after refresh. Pronunciation pauses source media; source playback stops pronunciation.
- Preserved launchers, routes, data models, twelve languages, locale/script settings, native/extension sources and authorized translation/speech integrations. No new runtime dependency, framework change, schema migration, external deployment or push.

## Limits

- Council generation is unavailable until an authorized conversational AI integration exists. There is no live or canned teaching dialogue masquerading as analysis.
- Broad context-aware translation still needs the existing configured provider. Offline dictionary matches are possible senses, not automatic sentence-level inference. Unsupported in-depth analysis is omitted.
- UI chrome remains English. Meaning language can be selected independently from the learning language; the curated Arabic catalogue retains its authored English annotations.
- Own-text resume stores one latest reading session per profile/account locally. It is not cross-device sync or a media-file backup. User-selected media must be reattached after refresh; no automatic transcript synchronization or import was added.
- Verification limits, especially native browser layout/accessibility and physical-device testing, are in `VERIFICATION_1.16.md`. Earlier screenshots and test counts in the archive are historical evidence, not 1.16 validation.
