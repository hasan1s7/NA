# Founder pages

The app links to `about.html` in its sidebar and footer. The public biography is adapted from Hasan's master CV. Unresolved degree labels, conflicting employment dates and savings figures are omitted. Paper status and existing authorship order are retained; anonymous project drafts do not receive invented bylines. Personal phone and leave details are not in the public page.

`patrick.html#edit` opens Patrick's profile workspace. Drafts use a separate `nabu:patrick-profile-draft:v1` localStorage key. No learner database, account, or application settings are accessed. Save is local only. Preview renders text through DOM `textContent`; website links only allow HTTP(S). Download exports a bounded JSON object. Nothing is uploaded or published by the editor.

To publish Patrick's completed profile:

1. Have Patrick download `patrick-profile.json` from the form.
2. Review its contents and replace `public/patrick-profile.json`.
3. Run `python tools/build_pages.py` and commit the source and root copy.
4. Push to the Pages branch. The public Patrick page reads the published JSON.

Editorial HTML is generated by `tools/build_about.py`, called by the existing standalone builder. `public/about.css`, `public/patrick.js`, and `public/patrick-profile.json` remain editable sources. `tools/build_pages.py` mirrors these and both HTML pages to the branch Pages root. Existing app modules, vocabulary stores, and learner behavior are unchanged.

These are static pages. Browser drafts are neither authenticated owner edits nor shared server persistence. A browser reset can remove a draft; downloading is the portable backup.
